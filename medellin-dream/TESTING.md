# 测试记录

验收环境为 Node.js 24、Vite 6 和 Chromium。单元测试直接验证磁盘文件与数据校验。端到端测试在临时项目中运行实际的应用代码和写入接口，避免把测试创作内容写入交付项目。

## 本次执行结果

| 命令 | 结果 |
| --- | --- |
| `npm test` | 3 项通过。 |
| `npm run test:e2e` | 6 个 Chromium 验收场景及 1 个总测试通过。环境为 Chromium 156.0.8078.79 和 Node.js 24.22.3。 |
| `npm run build` | TypeScript 类型检查和 Vite 生产构建通过。交付目录的正式内容保持默认配置。 |
| `npm run apply` 对应脚本 | 在临时目录分别应用到草稿和正式项目，解析后的文件与导入数据一致。 |

托管预览的端口转发超时。实际浏览器验证通过测试脚本启动的本地开发与生产服务完成。

## 验收操作

| 验收项 | 验证操作 |
| --- | --- |
| 1 | 从桌面和任务栏打开多个窗口，测试暂不可用提示、窗口置顶、最小化与恢复、最大化与还原、拖拽、缩放和关闭。 |
| 2–3 | 在工作室创建联系人、上传头像、修改昵称，在实时预览检查名片，并验证保存后的素材 ID。 |
| 4–6 | 创建单聊和群聊，设定群成员、群昵称、发送者与时间，在浏览器里实际拖拽两条消息换序。 |
| 7–8 | 新建动态、上传图片并打开图片预览，添加点赞、评论和回复。 |
| 9–10 | 手动保存草稿，读取 `data/draft.json` 核对，打开全屏玩家预览，发布至正式内容文件。 |
| 11–12 | 点击聊天头像，核对对应账号，通过名片进入个人朋友圈。 |
| 13、16 | 测试找不到账号、账号锁定、重复添加和登录解锁。工作室另行配置条件规则并校对保存结果。 |
| 14 | 点击群聊内部链接，验证学生系统、错误密码反馈、虚构登录，以及浏览器搜索、前进、后退、刷新、主页和 404。 |
| 15 | 编辑备忘录和回收站文件，检查正式预览和磁盘内容。 |
| 17 | 刷新浏览器、关闭重启 Vite、重新打开草稿，验证头像和内容持久化。导出再导入项目，并检查撤销、重做及自动保存。 |
| 18 | 构建含正式验收资源的临时项目，扫描生成的 JS；打开生产地址的 `#studio` 并检查写入接口。 |
| 19 | 在交付目录执行 `npm run build`，检查输出仅包含玩家端资源。 |

另验收 390 px 窄屏聊天、测试会话与正式玩家存档隔离、磁盘写入的版本冲突、同源校验和拒绝超出工作目录的写入目标。测试源码位于 `tests/browser.e2e.mjs` 和 `tests/project.test.mjs`。

## 重跑

```sh
npm ci
npm test
npm run build
CHROMIUM_PATH=/path/to/chromium npm run test:e2e
```

也可按 [README.md](README.md) 手动打开默认测试项目，从「星之队闲聊」进入学生系统，再使用 ARG Studio 进行创作验证。
