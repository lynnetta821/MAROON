# 麦德林之梦

《麦德林之梦》第一阶段的网页 ARG 创作框架。星屿 OS 提供虚构电脑桌面，ARG Studio 提供同一套游戏界面的可视化内容编辑和模拟预览。示例人物、聊天、动态、学生系统及账号均为演示占位。

## 启动

需要 Node.js 20.19+ 或 22.12+ 及 npm。使用本机浏览器访问终端给出的回环地址，默认是 `http://127.0.0.1:5173/`。

```sh
npm ci
npm run dev
```

Windows 用户也可以双击同目录的 `start-studio.cmd`。安装 Node.js LTS 后，启动器会在首次运行时安装项目依赖，并用本机浏览器打开工作室。编辑期间保留启动窗口。如果启动器没有找到项目，请粘贴解压后的 `medellin-dream` 文件夹路径。该文件夹应包含 `package.json` 和 `src`。如果浏览器没有自动打开，请用终端显示的地址并加上 `/#studio`。

双击源码的 `index.html` 会显示启动说明。若只想离线试玩，可用浏览器打开 `demo/medellin-desktop-demo.html`。

首次启动会看到标注「测试会话」的桌面，绿泡泡内有「星之队闲聊」。右上角进入 ARG Studio。有正式内容后，本地首页默认展示正式玩家模式，可用 `#demo` 打开独立测试会话。开发环境中的 `#studio` 也可直接进入工作室，`#player` 可体验当前已发布内容。

## 玩家的操作

- 单击桌面图标或任务栏打开应用。拖动窗口标题栏移动，拖动右下角改变大小，可用标题栏按钮最小化、还原、最大化及关闭。点击窗口会置顶。
- 绿泡泡支持聊天列表、联系人搜索、通讯录、添加好友与朋友圈。群聊标题右侧可展开成员与公告。头像会打开同一个联系人 ID 对应的名片，通过名片可进入该人的朋友圈或聊天。
- 在测试群点击「学生信息系统 · 测试入口」打开 `campus.local`。桌面的工作备忘录提供仅限游戏使用的虚构账号 `40350947` 和密码 `JXXY0000`。成功登录可解锁演示联系人 `demo.locked`。该账号只用于测试流程。
- 游戏浏览器的地址栏负责内部网址，关键词框负责匹配作者提供的资料。回收站和备忘录可搜索、打开条目并查看作者配置的附件。桌面左下角和系统名称均可打开虚构系统说明。

## 使用 ARG Studio

工作室左侧是模块与资源列表，中间是互动预览，右侧是属性。选择资源后，预览会定位到对应会话、联系人名片、朋友圈、页面或文件。小屏可切换资源、预览和属性面板。用「玩家预览」体验完整窗口。预览区下方「模拟剧情状态」可组合开关、好友关系、登录权限和线索，重置后会清空模拟初始状态。

| 模块 | 操作 |
| --- | --- |
| 桌面应用 | 新建或复制应用，设置行列、图标、可用状态、任务栏与点击行为。竖列主题跟随资源排序，网格主题使用配置的行列。 |
| 联系人 | 新建联系人，填写昵称、虚构账号、名片和可见字段。勾选初始好友，或开启账号搜索并增加解锁条件。可以在联系人页加入已有群聊。 |
| 单人聊天与群聊 | 为单聊指定对象，为群聊选择成员及群昵称。通过「新增消息」选发送者、类型、时间、内容和附件。拖动手柄排序，也可用上移和下移按钮。系统和日期消息可直接填写显示文本。 |
| 朋友圈 | 选择发布者，添加正文、时间和地点。上传或选择素材，再按「加入动态」，可排列最多九张图片。添加虚构点赞、评论及对已有评论的回复。个人封面在联系人页设置。 |
| 页面、搜索与账号 | 创建内部网址，选择文章或学生系统模板。为结果配置关键词、摘要、缩略图、排序与目标页。在页面管理的浏览器全局面板中可指定主页与 404 页。虚构账号需关联学生系统页面。 |
| 备忘录和回收站 | 新建或复制条目，编辑标题、日期、正文、附件及可见条件。条目附加行为可用于展示提示、收集线索或跳转页面。 |
| 剧情和线索 | 先建剧情状态、线索或事件，再在资源属性中选择条件及行为。事件按列表顺序执行。阅读行为在消息进入可见阅读区域时触发一次。 |
| 全局主题 | 设置壁纸、纯色背景、窗口色、边框、字体、字号、消息间距、圆角和布局。默认窗口尺寸在新开窗口时生效。 |

条件编辑器支持「全部满足（AND）」和「任一满足（OR）」，每条规则可要求目标为真或假。状态、好友、线索、已登录账号都可作为目标。点击行为面板提供应用、名片、聊天、朋友圈、图片、文件、内部网址、弹窗、收集线索、设置状态、解锁和触发事件。用「使用默认行为」恢复相应元素的标准操作，用「无行为」清除操作。要让同一动态在不同阶段显示不同正文或图片，可复制成两个版本并设置互斥条件。

## 数据、素材与发布

| 数据 | 保存位置 | 使用场景 |
| --- | --- | --- |
| 默认配置 | `data/default.json` | 恢复原始桌面与主题 |
| 创作草稿 | `data/draft.json` | 修改后自动写盘，也可用「保存草稿」或 Ctrl/Cmd+S |
| 正式游戏内容 | `data/published.json` | 发布后立即供本地正式玩家模式读取，构建时进入静态站 |
| 玩家进度 | 当前站点的浏览器存储 | 记录游戏内好友、剧情状态、线索、阅读标记和虚构登录状态 |
| 开发测试项目 | `src/studio/demo.ts` | 独立测试会话与可载入的占位草稿 |

- 在素材库可上传、预览、搜索名称或分类、重命名、下载或替换原文件。头像、群头像、壁纸和消息编辑器也可直接上传。SVG 以图片方式渲染，音频可在素材或附件查看器中播放。
- 素材按稳定 ID 引用，以 Base64 形式随项目保存和导出。替换同 ID 的文件会同步更新使用它的界面。删除仍被引用的素材时，工作室会列出对应位置。单件素材上限 8 MiB，单个保存请求上限 36 MiB。
- 编辑后可撤销或重做，最多保留 50 次本次打开的修改。刷新或重启时会从磁盘恢复最近保存的草稿。刚改完就离开时，请等状态显示「项目草稿已保存」。版本冲突时可导出当前草稿，再刷新读取新版本。
- 在「项目文件」可导出完整项目、导入 JSON、校验引用、恢复默认配置或载入测试项目。离线回退时会明确显示「浏览器草稿」，并用 IndexedDB 保存。使用下方命令可应用导出的完整项目。
- 要发布正式内容，请先在项目文件中移除测试资源并修正残余引用。也可以恢复默认配置后新建内容。编辑带 `demo-` ID 的记录会保留其测试身份。复制资源可创建正式 ID，相关引用仍需指向正式资源。
- 通过「玩家预览」检查草稿，再点击「发布」。校验通过后确认写入。工作室只在回环地址的开发模式加载，开发写入接口仅在回环绑定的 Vite 开发服务注册，并检查同源、请求凭据、项目结构和文件版本。部署时仅上传构建输出。

```sh
# 应用导出配置到开发草稿
npm run apply -- "/path/to/medellin-project.json" --draft

# 校验并应用到正式游戏内容
npm run apply -- "/path/to/medellin-project.json"

# 构建静态产物，并以生产模式检查内容
npm run build
npm run preview
```

Cloudflare Pages 的构建命令填写 `npm run build`，输出目录填写 `dist`。GitHub Pages 可上传或在 Actions 中部署 `dist`。构建使用相对路径，游戏内导航在应用内部完成。虚构账号与解锁规则随静态游戏交付，作者应当按可公开的谜题内容设计这些数据。

## 目录

```text
src/
  art/        原创桌面壁纸
  game/       类型、资源校验、玩家状态、共享交互接口
  ui/         桌面、窗口管理、聊天、浏览器、备忘录与回收站
  studio/     开发工作室、属性面板、草稿管理、独立演示数据
  styles/     桌面、游戏应用及编辑器样式
data/         默认配置、正式内容及本地草稿
scripts/      本地开发写入、文件校验及导入应用命令
tests/        持久化与 Chromium 浏览器回归
```

## 验证

```sh
npm test
npm run build
CHROMIUM_PATH=/path/to/chromium npm run test:e2e
```

Linux 环境可使用默认的 `/usr/bin/chromium` 或 `/usr/bin/google-chrome`。端到端测试将当前代码复制到临时项目，在 Chromium 中操作实际界面，启动与重启 Vite，读取保存文件，再构建和访问静态生产版本。测试结束后的源码与正式项目内容保持独立。详细结果见 [TESTING.md](TESTING.md)。
